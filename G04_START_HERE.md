# CSC 4110 — Group G04 repository starter

This package contains the **seven folders required by the university assignment** and an untouched copy of the supplied notebook template. It is a starter **folder structure only**, not a completed practical assessment.

## Upload to existing GitHub repository

1. Extract the downloaded ZIP to a folder on your computer.
2. Open that extracted folder. **Do not upload the ZIP directly**; GitHub will not extract it for you.
3. Go to `https://github.com/FestusAI/CSC4110-G04` on the **Code** tab.
4. Choose **Add file → Upload files** (on narrow layouts, use the small `+` menu near **Go to file**).
5. Drag the **seven subfolders** (`data`, `notebooks`, `models`, `outputs`, `app`, `report`, `tests`) and optionally this guide file into the upload area. Do **not** drag the enclosing extracted folder, or your repository may gain an unwanted extra nested directory.
6. Verify the preview paths begin with `data/`, `notebooks/`, etc., not with an extra `CSC4110-G04/` directory.
7. Commit with message `Set up G04 project folders and starter notebook` on the `main` branch.

GitHub already has your top-level `README.md` and `.gitignore`; this package does not overwrite either. Any existing `data/README.md` is also left untouched.

## Next steps

- Create and share the matching `CSC4110_G04` folder on **Google Drive**, with seven identical subfolders.
- Download the public `credit_risk_dataset.csv` from Kaggle and place it in the Drive `data` folder.
- Begin Task 1 in Colab, followed by Task 2.1 and Task 2.2 in order.
- Edit the supplied notebook template before running it: its group and dataset names are placeholders.
- Give all assigned members access to the GitHub repo and Drive folder. Every task owner must write, run, review, commit and submit their own designated work.
